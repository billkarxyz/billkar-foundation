# BILLKAR FOUNDATION

Website for BILLKAR FOUNDATION, a Web3 and crypto services organization:
ambassador programs, ICO / IDO / IEO, airdrops, testnets, DeFi, and NFTs.

Built with [Next.js](https://nextjs.org) (App Router, TypeScript,
Tailwind CSS, Framer Motion).

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server (port 4000):

```bash
npm run dev
```

Open http://localhost:4000 with your browser to see the site.

## Build

```bash
npm run build
```

## Project structure

- `app/` — pages and layout (the homepage is `app/page.tsx`)
- `components/` — UI components, including the service cards
- `data/` — content data
- `public/` — static assets
